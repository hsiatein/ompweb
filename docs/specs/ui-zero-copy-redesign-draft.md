# omp-web「去说明书化」UI 与文案重构草稿

> **设计信条**：如果一个界面需要一段话来解释“怎么点、生效顺序是什么、留空代表什么、背后写了什么文件”，说明控件结构本身画错了。凡是能用**布局层级、视觉状态、图标、即时预览**表达的信息，文字一律归零。

### 1. 设置页：砍掉所有大标题副标题、小节副标题、同义反复描述与作用域角标
- **现状问题**：
  - 每个设置页有 **4 层文字堆叠**：
    1. 左侧导航栏标题 + 副标题（如 `智能体与策略` / `指令、子智能体、上下文、记忆、重试与工具审批`）
    2. 右侧页面大标题 + 副标题（再重复一遍上面那句话）
    3. 小节标题 + 小节描述（如 `自动重试` / `失败回合的自动重试规则。`）
    4. 卡片标题 + `原生 OMP` / `界面` / `工作区` 角标 + 卡片描述（如 `自动重试` + `原生 OMP` + `自动对失败的回合进行重试。`）
  - 用户关心的只是功能本身，根本不关心某个开关存在 `localStorage`（`界面`）还是 `~/.omp/agent/config.yml`（`原生 OMP`）。
- **设计替代方案**：
  - **彻底删除**所有分类页顶部的 `<p className="settings-content-subtitle">`、所有小节副标题、以及卡片上的 `界面 / 原生 OMP / 工作区` 胶囊角标。
  - **砍掉 70% 的卡片描述（`description`）**：只要标题 + 右侧控件已经自明（如 `完成提示音 [开关]`、`自动朗读助手回复 [开关]`、`朗读语音 [下拉]`、`聊天字体大小 [下拉]`、`保持工具调用折叠 [开关]`），卡片就只渲染单行 `[图标/标题] ──────── [控件]`。
  - **用父子折叠代替解释关系**：
    - 关闭 `自动压缩` 时，下方的 `压缩后继续执行 / 压缩策略 / 回合中途压缩` 自动收起或半透明缩进；
    - `记忆后端` 选为 `关闭` 时，下方的 5 个记忆子开关自动收起；
    - 关闭 `自动重试` 时，`最大重试次数 / 模型回退降级` 自动收起。

### 2. 自定义指令（`AgentInstructionsConfig.tsx`）：砍掉全部 4 段说明文字，做成“继承链面包屑 + 显式开关”
- **现状问题**：
  - 界面上有 **4 段长文字** 教用户怎么理解规则：
    1. `agentInstructions.description`：「模型 > 提供商 > 全局。只采用最具体的一套，不叠加。模型规则按提供商 ID 和模型 ID 精确匹配。」
    2. `agentInstructions.idsHint`：「从已有提供商中选择，再选择其可用模型；切换提供商会清空模型选择。」
    3. `agentInstructions.emptyHint`：「留空并保存表示屏蔽上级自定义指令；删除规则则恢复继承。」（典型暗门设计）
    4. `agentInstructions.applies`：「配置保存在服务端，在主会话下一条消息开始执行时应用（含排队消息），不打断当前响应。保留原有系统与项目指令，不修改 AGENTS.md。升级前已启动的会话需先重启一次。」
- **设计替代方案**：
  1. **全部删掉以上 4 段话**。
  2. **用可视化优先级链代替第一段话**：顶部直接画一条可点击的层级流：
     `[ 🌐 全局 ] ──▸ [ 🏢 提供商: anthropic ] ──▸ [ 🤖 模型: claude-sonnet-4 ] (当前生效)`
     哪一级有规则就亮起圆点，最终生效的那一级高亮描边——不需要一个字解释“模型 > 提供商 > 全局，不叠加”。
  3. **把“留空=屏蔽上级”改成显式三态分段控件**：
     `[ 继承上级 ]  [ 自定义指令 ]  [ 🚫 屏蔽上级指令 ]`
     选“继承上级”即删除当前层规则；选“屏蔽上级”即隐藏文本框并显示禁令图标。

### 4. 子智能体管理（`AgentsConfig.tsx`）：删掉原子写入声明、CSV 标签与冗余说明
- **现状问题**：
  - `settingsConfig.agentsDesc`：「管理子智能体定义、模型角色与工具。解包内置模板后即可编辑。」
  - `agentsConfig.createAgentDesc`：「创建用于委托任务和会话的持久 OMP 智能体。」
  - `agentsConfig.atomicNotice`：「写入操作为原子级（临时文件 + 重命名），安全支持符号链接且上限 512 KB。路径均经过校验以确保位于 agents 目录内。」
  - `agentsConfig.bundledReadOnlyWarning`：「内置智能体为只读模板。保存将在 {scope} 作用域中创建可编辑副本。」
  - 字段名写着 `模型角色 (CSV)`、`可派生子代理 (CSV 或 *)`、`工具 (CSV)`。
- **设计替代方案**：
  1. **直接删除** `agentsDesc`、`createAgentDesc`、`atomicNotice`、`templatesNotice`。
  2. **把 CSV 文本输入框改成 Tag 胶囊输入（Chip Input）**：输入 `read` 回车就变成 `[read ×]` 胶囊，`spawns` 提供 `[允许全部 (*)]` 快捷切换，从此不再需要 `(CSV 或 *)` 这种程序员提示。

## 四、什么时候必须保留文字

删说明不删信息。以下四类必须留字（尽量 ≤15 字，放在控件旁）：

1. **不可逆后果**：删除、断开、覆盖、归档等确认弹窗。
2. **安全边界**：sudo 密码去向、密钥不回显、Webhook 令牌即凭据。
3. **看不出来的行为**：按服务器时区计时、「仅此设备」（浏览器本地保存）、运行中提交=引导/排队、0 表示不限。
4. **错误与状态**：失败原因、不支持（如浏览器不支持朗读）。

被删掉的描述文字仍保留在语言包与 `SETTING_INDEX` 里，作为设置搜索的关键词。

## 五、已定决策

- Web 以桌面为设计目标（可用悬停提示）；RN App 单独适配手机，不依赖悬停，文案硬编码在组件中，只有设置搜索索引由 Web 的 zh-CN 生成。
- 作用域角标只保留一个「仅此设备」，其余（原生 OMP）不标。
- 父子设置：子项缩进挂在父开关下，父项关闭时子项变灰且不可操作，不隐藏。
- 次要说明放进「?」（`InfoHint`，`components/ui/primitives.tsx`）：电脑上悬停显示，手机上点一下显示、再点一下隐藏。条件/行为用小徽章（`.hint-chip`），如「空输入且空闲时」「忙时排队」「服务器发送」。
- 与草稿不同之处：定时发送的说明不删，改为「服务器发送」徽章 + ?；更新弹窗保留「会停止 N 个运行中的会话」（仅在有运行中会话时显示），其余 4 条删除，进度由已有步骤列表表达；sudo 弹窗保留安全说明（锁图标一行），倒计时改为标题旁徽章。
